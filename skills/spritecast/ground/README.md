# Ground plants for `ground.py meadow`

`realistic/` - grass, fern, wildflowers, clover: made for SpriteCast with Tripo (text to 3D), textured, about 2,000 faces each. MIT, like
the rest of this repository. The meadow and path of the Rain Girl demo were rendered from these. Your own plants: "plants" in the spec,
a list of {"glb", "kind", "height"}.
